1. OVERVIEW & INTRODUCTION
================================================================================

TradingView Lightweight Charts is a high-performance, open-source JavaScript 
library for creating interactive financial charts. It is developed and 
maintained by TradingView.

Key Characteristics:
- Size: Only ~35 KB (compressed)
- Technology: HTML5 Canvas
- License: Apache License 2.0
- Languages: TypeScript (primary), JavaScript
- Browser Support: ES2020+ compatible browsers

Official Website: https://www.tradingview.com/lightweight-charts/
GitHub Repository: https://github.com/tradingview/lightweight-charts
NPM Package: https://www.npmjs.com/package/lightweight-charts
Documentation: https://tradingview.github.io/lightweight-charts/

Current Version: 5.1.0 (as of 2025/2026)
GitHub Stats: ~13,940 stars, ~2,177 forks

ATTRIBUTION REQUIREMENT:
The license requires specifying TradingView as the product creator. Add:
- Attribution notice from the NOTICE file on GitHub
- Link to https://www.tradingview.com

---------------
The library ships with multiple build variants:

---------------------|--------|------------------------------------|--------------------------------

4. SERIES TYPES
================================================================================

4.1 AREA SERIES
---------------
Definition: AreaSeries
Data Format: SingleValueData or WhitespaceData
Description: Colored area between time scale and line connecting data points

Example:
const areaSeries = chart.addSeries(AreaSeries, {
    lineColor: '#2962FF',
    topColor: '#2962FF',
    bottomColor: 'rgba(41, 98, 255, 0.28)'
});

4.2 BAR SERIES
---------------
Definition: BarSeries
Data Format: BarData or WhitespaceData
Description: Vertical bars showing price movements (high-low range)
             Open/close shown as tick marks

4.3 BASELINE SERIES
-------------------
Definition: BaselineSeries
Data Format: SingleValueData or WhitespaceData
Description: Two colored areas above/below a base value line

Example:
const baselineSeries = chart.addSeries(BaselineSeries, {
    baseValue: { type: 'price', price: 25 },
    topLineColor: 'rgba(38, 166, 154, 1)',
    topFillColor1: 'rgba(38, 166, 154, 0.28)',
    bottomLineColor: 'rgba(239, 83, 80, 1)',
    bottomFillColor1: 'rgba(239, 83, 80, 0.28)'
});

4.4 CANDLESTICK SERIES
----------------------
Definition: CandlestickSeries
Data Format: CandlestickData or WhitespaceData
Description: Solid body (open-close), wicks (high-low)

Example:
const candlestickSeries = chart.addSeries(CandlestickSeries, {
    upColor: '#26a69a',
    downColor: '#ef5350',
    borderVisible: false,
    wickUpColor: '#26a69a',
    wickDownColor: '#ef5350'
});

Data format: { time, open, high, low, close }

4.5 HISTOGRAM SERIES
--------------------
Definition: HistogramSeries
Data Format: HistogramData or WhitespaceData
Description: Columns showing value distribution (can have individual colors)

Example:
const histogramSeries = chart.addSeries(HistogramSeries, {
    color: '#26a69a'
});

4.6 LINE SERIES
---------------
Definition: LineSeries
Data Format: LineData or WhitespaceData
Description: Data points connected by straight line segments

4.7 CUSTOM SERIES (PLUGINS)
---------------------------
Create custom series types by implementing ICustomSeriesPaneView interface.
Use addCustomSeries() method to add to chart.

================================================================================
4B. CHART TYPES
================================================================================

Lightweight Charts offers different types of charts to suit various data 
visualization needs.

4B.1 STANDARD TIME-BASED CHART
------------------------------
- Creation method: createChart
- Horizontal scale: Time-based
- Use case: General-purpose charting for financial and time series data
- Most common chart type

4B.2 YIELD CURVE CHART
-----------------------
- Creation method: createYieldCurveChart
- Horizontal scale: Linearly spaced, defined in monthly time duration units
- Key differences:
  * Whitespace is ignored for crosshair and grid lines
  * Specialized for yield curve representation
- Use case: Displaying yield curves, common in financial analysis

Example:
const chart = createYieldCurveChart(document.getElementById('container'), options);
const curve = [
    { time: 1, value: 5.378 },   // 1 month
    { time: 2, value: 5.372 },   // 2 months
    { time: 12, value: 4.739 },  // 1 year
    { time: 60, value: 3.887 },  // 5 years
    { time: 120, value: 4.007 }, // 10 years
];

4B.3 OPTIONS CHART (PRICE-BASED)
--------------------------------
- Creation method: createOptionsChart
- Horizontal scale: Price-based (numeric)
- Use case: Visualizing option chains, price distributions
- Price is the primary x-axis metric instead of time

Example:
const chart = createOptionsChart(document.getElementById('container'), options);
for (let i = 0; i < 1000; i++) {
    data.push({
        time: i * 0.25,  // Price values
        value: Math.sin(i / 100) + i / 500,
    });
}

4B.4 CUSTOM HORIZONTAL SCALE CHART
-----------------------------------
- Creation method: createChartEx
- Horizontal scale: Custom-defined
- Use case: Specialized charting needs with non-standard horizontal scales
- Use with defaultHorzScaleBehavior for customization

================================================================================
4C. PRICE SCALE
================================================================================

The price scale (or price axis) is a vertical scale that maps prices to 
coordinates and vice versa.

CREATE PRICE SCALE:
- By default, chart has two visible price scales: left and right
- Can create unlimited overlay price scales (hidden in UI)
- Overlay price scales allow series to be plotted without affecting existing scales
- Useful for indicators like Volume with different values from price data

MODIFY PRICE SCALE:
- Left price scale: leftPriceScale option
- Right price scale: rightPriceScale option
- Overlay price scales: overlayPriceScales option

REMOVE PRICE SCALE:
- Default left/right scales cannot be removed, only hidden (visible: false)
- Overlay price scale exists as long as at least one series is attached

PRICE SCALE MODES:
- Normal: Standard price display
- Logarithmic: Logarithmic scale
- Percentage: Percentage change from first point
- Indexed: Indexed values

================================================================================
4D. TIME SCALE
================================================================================

The time scale (or time axis) is a horizontal scale displaying time of 
data points at the bottom of the chart.

TIME SCALE API:
- Get time scale: chart.timeScale()
- Methods: setVisibleRange, getVisibleRange, setVisibleLogicalRange, 
           getVisibleLogicalRange, fitContent, resetTimeScale

VISIBLE RANGE:
- Data range: Includes values from first to last visible bar
- Logical range: Continuous line of values with bar indices
- Note: Cannot extrapolate time with setVisibleRange

CHART MARGIN:
- Space between chart borders and series
- Controlled by barSpacing (default: 6) and rightOffset (default: 0)
- Use fitContent() to auto-fit all data

TIME FORMATS:
- String: '2023-01-01' (yyyy-mm-dd)
- Unix timestamp: 1640995200 (seconds)
- BusinessDay: { year: 2023, month: 1, day: 1 }

4E. PANES (MULTI-PANE SUPPORT)
================================================================================

Version 5.0 introduced multi-pane support - one of the most requested features.

FEATURES:
- Full support for multiple panes within a single chart
- Independent scale and series management per pane
- Flexible pane sizing and arrangement options

PANE API:
- chart.panes(): Get array of pane APIs
- chart.addPane(): Add new pane programmatically
- pane.attachPrimitive(): Attach primitives to pane
- pane.getHTMLElement(): Get pane's DOM element

STRETCH FACTORS:
- getStretchFactor(), setStretchFactor() for relative pane sizes

5. API REFERENCE (MAIN FUNCTIONS & INTERFACES)
================================================================================

5.1 CREATE CHART
----------------
import { createChart } from 'lightweight-charts';

const chart = createChart(container, options);
// container: DOM element
// options: ChartOptions (optional)

Returns: IChartApi object

5.2 MAIN INTERFACES
-------------------
- IChartApi: Main interface for single chart (remove(), resize(), addSeries(), etc.)
- ISeriesApi: Interface for series (setData(), update(), applyOptions(), etc.)
- ITimeScaleApi: Time scale management (fitContent(), setVisibleRange(), etc.)
- IPriceScaleApi: Price scale management

5.3 KEY METHODS
---------------
// Chart methods
chart.remove()                    // Remove chart and all DOM elements
chart.resize(width, height)       // Resize chart
chart.addSeries(SeriesType)       // Add new series
chart.timeScale()                 // Get time scale API
chart.panes()                     // Get pane APIs

// Series methods
series.setData(data)              // Set all data (replaces existing)
series.update(data)               // Update last point or add new
series.applyOptions(options)      // Apply new options
series.priceScale()               // Get price scale API

// Time scale methods
timeScale.fitContent()            // Fit content to view
timeScale.setVisibleRange(range)   // Set visible time range
timeScale.subscribeVisibleRangeChange(callback)  // Subscribe to range changes

5.4 ENUMERATIONS
----------------
- MarkerSign: arrowUp, arrowDown, circle, square, triangleUp
- ColorType: Solid, Gradient
- CrosshairMode: Normal, Magnet
- LastPriceAnimationMode: Continuous, OnDataUpdate, Disabled
- LineStyle: Solid, Dotted, Dashed, LargeDashed, SparseDotted
- LineType: Simple, WithSteps
- PriceScaleMode: Normal, Logarithmic, Percentage, Indexed

5.5 DATA FORMATS
----------------
// SingleValueData (Area, Baseline, Line)
{ time: '2023-01-01' | 1640995200, value: 123.45 }

// CandlestickData
{ time: '2023-01-01', open: 100, high: 110, low: 95, close: 105 }

// BarData
{ time: '2023-01-01', open: 100, high: 110, low: 95, close: 105 }

// HistogramData
{ time: '2023-01-01', value: 50, color: 'red' }

// WhitespaceData (gaps)
{ time: '2023-01-01' }

Time formats: 
- String: '2023-01-01' (yyyy-mm-dd)
- Unix timestamp: 1640995200 (seconds)
- BusinessDay: { year: 2023, month: 1, day: 1 }

// Basic React implementation
import { createChart } from 'lightweight-charts';
import { useEffect, useRef } from 'react';

function ChartComponent() {
    const chartContainerRef = useRef();
    
    useEffect(() => {
        const chart = createChart(chartContainerRef.current, {
            width: 800,
            height: 400
        });
        
        const series = chart.addCandlestickSeries();

        return () => chart.remove();
    }, []);
    
    return <div ref={chartContainerRef} />;
}

13. COMPREHENSIVE API QUICK REFERENCE
================================================================================

MAIN FUNCTIONS:
---------------
createChart(container, options)        - Create standard time-based chart
createYieldCurveChart(container, opts)  - Create yield curve chart
createOptionsChart(container, options)  - Create price-based chart
createChartEx(container, behavior, opts)- Create chart with custom scale
createTextWatermark(chart, options)    - Create text watermark
createImageWatermark(chart, options)   - Create image watermark
createSeriesMarkers(series, options)   - Create series markers
createUpDownMarkers(series, options)   - Create up/down markers
version                                - Get library version

SERIES TYPES (Exports):
-----------------------
AreaSeries, BarSeries, BaselineSeries, CandlestickSeries, 
HistogramSeries, LineSeries

ISERIES API METHODS:
--------------------
setData(data)                  - Set all data (replaces existing)
update(data)                   - Update last point or add new
applyOptions(options)          - Apply new options
priceScale()                   - Get price scale API
markers()                      - Get markers
dataByIndex(index, interval)   - Get data by index
barsInLogicalRange(logicalRange)- Get bars info
setMarker(marker)              - Set single marker
remove()                       - Remove series

ICHART API METHODS:
------------------
remove()                       - Remove chart and DOM elements
resize(width, height)          - Resize chart
addSeries(SeriesType, opts)    - Add new series
addCustomSeries(instance, opts)- Add custom series
timeScale()                    - Get time scale API
priceScale(id)                 - Get price scale by ID
applyOptions(options)          - Apply chart options
subscribeClick(handler)        - Subscribe to click events
subscribeCrosshairMove(handler)- Subscribe to crosshair movement
subscribedDblClick(handler)    - Subscribe to double-click

ITIMESCALE API METHODS:
-----------------------
fitContent()                   - Fit all content in view
setVisibleRange(range)         - Set visible time range
getVisibleRange()              - Get visible time range
setVisibleLogicalRange(range)  - Set logical range
getVisibleLogicalRange()       - Get logical range
resetTimeScale()               - Reset to default
subscribeVisibleRangeChange(cb)- Subscribe to range changes
convertToIndex(time)            - Convert time to index
convertToTime(index)           - Convert index to time

IPRICESCALE API METHODS:
-----------------------
applyOptions(options)          - Apply price scale options
getOptions()                   - Get current options
setVisibleRange(range)         - Set visible range
getVisibleRange()              - Get visible range
setAutoScale(enabled)          - Enable/disable auto-scale

ENUMERATIONS REFERENCE:
-----------------------
CrosshairMode: Normal, Magnet, MagnetOHLC, Hidden
LineStyle: Solid, Dotted, Dashed, LargeDashed, SparseDotted
LineType: Simple, WithSteps
PriceScaleMode: Normal, Logarithmic, Percentage, Indexed
LastPriceAnimationMode: Continuous, OnDataUpdate, Disabled
ColorType: Solid, Gradient
MarkerSign: ArrowUp, ArrowDown, Circle, Square, TriangleDown, TriangleUp
